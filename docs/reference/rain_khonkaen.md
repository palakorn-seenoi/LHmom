# Annual Maximum Daily Rainfall for Khon Kaen

A dataset containing the annual maximum series (AMS) of daily rainfall
measurements in Khon Kaen, Thailand, from 1984 to 2025.

## Usage

``` r
data(rain_khonkaen)
```

## Format

A data frame with 42 rows and 2 variables:

- year:

  The observation year (1984-2025).

- max_rain:

  The annual maximum daily rainfall in millimeters (mm).

## Source

Thai Meteorological Department (TMD)
