# Annual Maximum Daily Temperature for Khon Kaen

A dataset containing the annual maximum series (AMS) of daily
temperature measurements in Khon Kaen, Thailand, from 1985 to 2025. This
dataset is useful for modeling extreme heat events.

## Usage

``` r
data(temp_khonkaen)
```

## Format

A data frame with 42 rows and 2 variables:

- year:

  The observation year (1985-2025).

- max_temp:

  The annual maximum daily temperature in degrees Celsius (°C).

## Source

Thai Meteorological Department (TMD)
